# Automação de Testes QA

## Sobre o projeto

Este projeto foi criado para praticar automação de testes de software, utilizando Python, Playwright e Pytest.

## Tecnologias utilizadas

- Python
- Playwright
- Pytest
- Git e GitHub

## Cenário de teste

### Login com sucesso

- Acessar o site Sauce Demo.
- Preencher o usuário de teste.
- Preencher a senha.
- Clicar no botão de login.
- Validar se o usuário foi direcionado para a página de produtos.

## Como executar os testes

1. Instale o Python.
2. Instale as dependências necessárias.
3. Instale os navegadores do Playwright.
4. Execute os testes com:

```bash
python -m pytest -v
```

## Objetivo

Desenvolver conhecimentos práticos em automação de testes, validação de regras de negócio e qualidade de software.
